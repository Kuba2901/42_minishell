tokenise -\/ Tokenizes the input string into a list of tokens. @input\+: The input string to be tokenized.

This function takes an input string and tokenizes it into a list of tokens. It handles different types of tokens including simple tokens (like \textquotesingle{}(\textquotesingle{}, \textquotesingle{})\textquotesingle{}, \textquotesingle{}$\vert$\textquotesingle{}, \textquotesingle{}$<$\textquotesingle{}, \textquotesingle{}$>$\textquotesingle{}), quoted strings, and words. The function skips over whitespace and processes each token accordingly. The resulting list of tokens is returned.

\begin{DoxyReturn}{Returns}
\+: A pointer to the list of tokens, or NULL if memory allocation fails.
