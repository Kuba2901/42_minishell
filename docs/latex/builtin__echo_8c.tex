Implements the {\ttfamily echo} built-\/in command for the minishell. 

This function mimics the behavior of the UNIX {\ttfamily echo} command, supporting the {\ttfamily -\/n} option to suppress the trailing newline. It expands environment variables within arguments and prints the result to standard output.
