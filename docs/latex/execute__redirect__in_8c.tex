Executes a command with input redirection. 

This function handles the execution of a command where the input is redirected from a file. It temporarily replaces the standard input (stdin) with the contents of the specified file, executes the command, and then restores the original stdin.


\begin{DoxyParams}{Parameters}
{\em shell} & Pointer to the shell structure containing environment and state information. \\
\hline
{\em node} & Pointer to the AST node representing the command and its redirection.\\
\hline
\end{DoxyParams}
The function performs the following steps\+:
\begin{DoxyEnumerate}
\item Duplicates the current stdin file descriptor to save it.
\item Expands the file name using environment variable expansion.
\item Opens the file for reading.
\item If the file cannot be opened, prints an error message and exits.
\item Redirects stdin to the opened file.
\item Executes the command represented by the left child of the AST node.
\item Restores the original stdin.
\item Closes the duplicated stdin file descriptor.
