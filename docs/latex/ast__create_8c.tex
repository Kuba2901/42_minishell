Creates an abstract syntax tree (AST) from a list of tokens. 

This function takes a list of tokens and constructs an AST node from it. If the list is empty or NULL, the function returns NULL. Otherwise, it delegates the creation of the AST to the {\ttfamily ast\+\_\+create\+\_\+pipe} function.
