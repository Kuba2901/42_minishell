{\footnotesize\ttfamily void signals\+\_\+setup (\begin{DoxyParamCaption}\item[{void}]{ }\end{DoxyParamCaption})}



Sets up signal handlers for the application. 

This function configures the signal handlers for SIGINT and SIGQUIT signals.
\begin{DoxyItemize}
\item SIGINT\+: When the SIGINT signal is received (typically generated by pressing Ctrl+C), the {\ttfamily signals\+\_\+handle\+\_\+sigint} function will be called to handle the signal.
\item SIGQUIT\+: The SIGQUIT signal (typically generated by pressing Ctrl+) will be ignored. 
\end{DoxyItemize}
