Changes the current working directory of the shell. 

This function implements the {\ttfamily cd} built-\/in command, allowing users to navigate the filesystem. It supports\+:
\begin{DoxyItemize}
\item {\ttfamily cd} or {\ttfamily cd $\sim$} to move to the home directory.
\item {\ttfamily cd -\/} to move to the previous working directory.
\item {\ttfamily cd $<$directory$>$} to move to the specified directory.
\end{DoxyItemize}

If the directory change is successful, it updates the {\ttfamily PWD} and {\ttfamily OLDPWD} environment variables. If it fails, an error message is printed.
