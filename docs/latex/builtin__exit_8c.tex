Handles the execution of the {\ttfamily exit} built-\/in command. 

This function checks if the {\ttfamily exit} command is properly formatted and executes it, freeing necessary resources before terminating the shell. The function ensures\+:
\begin{DoxyItemize}
\item The command is correctly formatted with a single {\ttfamily exit} keyword.
\item Argument validity is checked, allowing a numeric exit code.
\item The shell\textquotesingle{}s exit code is set appropriately.
\item Memory cleanup is performed before exiting.
\end{DoxyItemize}
