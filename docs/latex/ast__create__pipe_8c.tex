ast\+\_\+create\+\_\+pipe -\/ Creates an AST node for a pipe operation. @list\+: A pointer to the list of token nodes.

This function creates an abstract syntax tree (AST) node for a pipe operation by parsing the token list. It first creates the left node by calling ast\+\_\+create\+\_\+redirect. Then, it iterates through the token list to find pipe tokens (TOKEN\+\_\+\+PIPE). For each pipe token found, it creates a right node by calling ast\+\_\+create, and then creates a pipe node with the current token. The left and right nodes are assigned to the pipe node, and the left node is updated to the pipe node. The function returns the final left node, which represents the root of the pipe operation AST.
