t_environment_node * enviroment_node_create ( const char * entry,
t_shell * shell )

Creates an environment node from an entry string and adds it to the shell's environment list.

This function uses _node_from_entry to parse the entry string into a node. If successful, it inserts this node into the shell's environment list using _environment_node_insert. It returns the created node, or NULL if parsing fails.

Parameters
entryThe entry string to process.
shellA pointer to the shell context containing the environment list.
Returns
t_environment_node* A pointer to the newly created and inserted node, or NULL.

◆ environment_list_initialize()

t_environment_node * environment_list_initialize ( const char ** envp)

Initializes an environment list from an array of environment variable strings.

This function processes each string in the provided array using _node_from_entry to create nodes. Each valid node is inserted into the environment list. It returns the head of the newly created list, which may be empty if all entries are invalid.

Parameters
envpAn array of strings representing environment variables.
Returns
t_environment_node* The head of the environment list, or NULL if no nodes were created.
